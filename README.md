# 🐉 Wild Hunt

A Pokémon-inspired creature-taming RPG built with C++ / Python.
Roam dynamic environments, encounter wild creatures, and battle to tame them.

## 🚧 Status
Currently in active development — early stage.

## 🎮 About the Game
Wild Hunt is a text-based / 2D RPG where players:
- Explore different environments and biomes
- Encounter unique wild creatures
- Battle and tame creatures to build their collection
- Progress through an evolving world

## 🛠️ Built With
- C++
- HTML (UI/frontend elements)
